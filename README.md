# Lucro e Investimento — contas Mercado Livre

Painel estático (HTML + JS) que lê as planilhas das contas, audita erros e permite importar vendas do ML e lançar saídas.

- Sem backend e sem banco: as planilhas são lidas só no navegador.
- Importações e saídas ficam no `localStorage` do navegador (use "Exportar saídas" como backup).
- Use no Chrome ou Edge (sincronização de pasta).

**Não suba planilhas para este repositório.**
